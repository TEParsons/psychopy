.. _egi:

egi (pynetstation) 
=============================================

Support for egi is now provided via the `egi-pynetstation <https://github.com/nimh-sfim/egi-pynetstation>`__
third-party library. This is included within Standalone PsychoPy from 2022.2.0

See the `egi-pynetstation documentation <https://egi-pynetstation.readthedocs.io/en/latest/>`__
for further details.
